NEROPAY · ODOO 19

Payments where your business works.

Hosted NeroPay checkout for online orders and customer invoices.

Online checkout Invoice payments Odoo 19.0

One checkout. Verified payment status.

  • Native Odoo payment-provider configuration for Website, eCommerce and invoice payment flows.
  • NeroPay API v2 authentication, signed creation requests and stable order references.
  • Server-side verification of merchant account, transaction reference, amount and currency.
  • IPN-triggered verification, scheduled recovery and a Check NeroPay status button for authorised accounting users.
  • GBP, EUR and USD; merchant currency availability and payment limits still apply.
  • Direct merchant or authorised NeroConnect platform credentials with an explicit target account.

Hosting requirements

Requires Odoo 19.0 on a deployment that supports custom Python modules, such as Odoo.sh or self-hosted Odoo. This module cannot be installed on Odoo Online saas-19.4. A separate connector website is not required.

Getting started

  1. Install the module into a development environment and configure an HTTPS Odoo domain.
  2. Open Accounting / Configuration / Payment Providers / NeroPay.
  3. Enter the receiving merchant's exact public account ID and API v2 secret. Keep secrets server-side.
  4. Check API connectivity and configure a dedicated NeroPay clearing journal.
  5. Complete staging acceptance tests before enabling real payments and publishing the provider.

Clear scope

This release does not include POS terminal integration, saved payment tokens, automatic subscription renewals, refunds initiated in Odoo, payout/fee import or bank-settlement reconciliation. Subscription invoices can use an individual hosted checkout where Odoo offers the invoice payment flow. Paid transactions and bank settlements are different accounting events.

Do not use the API v2 dry-run sandbox to mark real orders paid. Odoo's Test state is intentionally blocked in this release. Use mocked automated tests and separately authorised live acceptance testing.

Release candidate: local contract and workflow tests are provided. Installation and end-to-end acceptance testing in your Odoo environment are required before production use.
